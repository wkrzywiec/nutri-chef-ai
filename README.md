# nutri-chef-ai

Let Nutri Chef AI spice up your week! This smart meal planner uses AI and a rich recipe database to whip up delicious, balanced meal plans tailored just for you.

## Services and tools

### Embeddings

The `/embeddings` dir contains Python script for transforming PostgreSQL data into vectorized data.

In order to execute it is highly recommended to create virtual env (`venv`):

```bash
python -m venv <path to the project>/embeddings
```

And then activate it (for Linux and Mac replace `Scripts` -> `bin`):

```bash
source <path to the project>/embeddings/Scripts/activate
```
